## Introduction

A lot of my professional work and previous posts focus on Go, Kubernetes, and backend architecture, but I've always had a soft spot for frontend development. In my free time I like to experiment with React and build tools and interfaces that work well and run fast.

Today I want to "show off" a couple of these projects, so you can see what I build when I'm not writing Go services.

## 1. Personal Portfolio

![Portfolio website screenshot](/img/portfolio.png)


Every developer needs a home on the web, and this is mine. I built the portfolio with React, and it collects my skills, experience, and projects in one place.

*   **URL:** [portfolio.noobygames.de](https://portfolio.noobygames.de)

When you visit, you'll see a responsive design, a sleek dark theme, and smooth animations. It shows my technical stack and professional journey, so it works as a dynamic resume.

The project keeps changing as I learn new frontend techniques. It's my playground for trying out new React patterns and library integrations.

## 2. Last War Calculators

![Last War Calculators Screenshot](/img/lw-calculator.png)

I play the mobile game "Last War" a lot, and I got tired of the tedious calculations for resource management and speed-up optimizations pretty quickly. So I built this React application, a set of practical tools for the community.

*   **URL:** [Last War Calculators](https://noobygames.github.io/last-war-calculators/)

The single-page application has several specialized calculators: a **Speedup Calculator**, a **Resource Calculator**, a **Hero EXP Calculator**, and a **Research Calculator**. Players enter their current resources and goals and get exactly what they need for their next upgrade. The interface is straightforward and designed mobile-first, so players who want to optimize their gameplay get an answer right away. Under the hood, React handles the calculation logic and state management, and a simple SPA (Single Page Application) turned out to be enough to solve a real problem for a niche community.

## Conclusion

Building these apps keeps me sharp on the full-stack side of things. Whether it's a Go microservice or a React calculator, I want clean, maintainable code that solves a problem.
